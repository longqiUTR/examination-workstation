## 1. 基础功能

### 1.1 登录

- [ ] 打开网站 → 首页若未登录应该跳到 `/login`
- [ ] 输入邮箱 → 点"发送登录链接"
- [ ] 1 分钟内收到邮件（检查垃圾箱）
- [ ] 点邮件链接 → 能正常跳回首页
- [ ] 退出（顶栏退出按钮）→ 再访问需重新登录

**如果登录发不出邮件：**
- 检查 SMTP 配置（`EMAIL_SERVER` / `EMAIL_FROM`）
- 端口：QQ 用 465（Gmail 也要 465，不要 25）
- Vercel 默认屏蔽 25 端口发件

### 1.2 刷题

- [ ] 题库页 `/questions` 能列出题目
- [ ] 选模块 + 难度 → 创建练习 → 进练习页
- [ ] 单选题：选一个选项 → 提交 → 显示对/错 + 解析
- [ ] 多选题：选多个 → 提交 → 判分
- [ ] 不定项：同多选
- [ ] 答对 3 次后，那道题在错题本里**自动消失**（如果之前错过）

### 1.3 错题

- [ ] 故意答错几道 → `/mistakes` 能看到
- [ ] 点错题 → 重做页能进入
- [ ] 写笔记 → 保存 → 刷新页面笔记还在
- [ ] 答对 3 次 → 错题消失

### 1.4 计划

- [ ] `/plans/new` 创建一个计划
- [ ] `/plans` 列表能看到
- [ ] 计划详情页能看到进度卡片
- [ ] 答对当日题目 → PlanTask 自动 mark done
- [ ] 已完成日期的 task 显示 ✓

### 1.5 统计

- [ ] `/stats` 折线图能渲染（按日期）
- [ ] 柱状图能渲染（按模块）
- [ ] 数据为空时显示占位（不报错）

### 1.6 Dashboard

- [ ] 首页显示今日任务数、累计答题数、掌握数
- [ ] 快速入口 4 个能点进去

## 2. PWA 移动端

### 2.1 iOS Safari

- [ ] 用 Safari 打开网站 → 底栏有"分享"按钮 → "添加到主屏幕"
- [ ] 添加后桌面出现"考工"图标
- [ ] 点桌面图标 → 启动后是**全屏**（无 Safari 地址栏）
- [ ] 启动后状态栏颜色 = theme-color（黑色）
- [ ] Manifest 名称 = "考工"（短名）

### 2.2 iOS PWA 离线

- [ ] 在联网状态刷 5-10 道题
- [ ] 设置 → 飞行模式
- [ ] 重新打开 PWA
- [ ] 之前刷过的题目能渲染（SW 缓存命中）
- [ ] 答案 / 解析在重做时仍能看到（IndexedDB 缓存命中）

### 2.3 iOS PWA 离线写

- [ ] 飞行模式 → 答一题
- [ ] 应该**立刻看到判分结果**（本地 judge）
- [ ] 关掉飞行模式 → 等几秒
- [ ] 答的题应该**最终同步到服务端**（打开 stats / 错题本验证）
- [ ] 离线状态刷新页面不能崩

### 2.4 Android Chrome

- [ ] Chrome 打开 → 地址栏右侧出现"安装"图标 → 安装
- [ ] 桌面 / 应用抽屉出现图标
- [ ] 启动是全屏 PWA 模式
- [ ] 离线读 + 离线写 + 联网同步（同样过 2.2 / 2.3 流程）

### 2.5 已知 PWA 限制

> 这些是浏览器限制，**不是 bug**：
> - iOS Safari：SW 在 PWA 关闭后可能被冻结，1-2 小时内不活跃
> - iOS：没有后台同步 API（用 `online` 事件触发，依赖用户重新打开 app）
> - Android Chrome：App Badging API 浏览器实现差异大

## 3. 兼容性 / 视觉

### 3.1 布局

- [ ] 横屏 / 竖屏切换不崩
- [ ] iPhone 14 / 15 Pro Max 顶部不顶到刘海
- [ ] 底部导航在 PWA 全屏模式下不被 home bar 遮住（iOS 有 safe-area）
- [ ] 文字不溢出（长题干、解析）

### 3.2 交互

- [ ] 提交按钮 loading 状态正常
- [ ] 切题流畅（无白屏）
- [ ] 错误提示显示明显（红色文字）
- [ ] 空状态有友好提示（不是空白页）

### 3.3 性能

- [ ] 首页 LCP < 2s（4G 网络）
- [ ] 切题 TTFB < 500ms
- [ ] 没有肉眼可见的卡顿

---

## 4. 数据一致性

- [ ] 答题后 → `/stats` 数字立刻 +1（revalidate 生效）
- [ ] 错题答对 → `/mistakes` 列表立刻少一个
- [ ] 计划 mark done → 进度条立刻动
- [ ] 离线答题 N 道 → 联网后 N 条都同步上去（数量对得上）

---

## 5. 安全

- [ ] 不登录直接访问 `/questions` / `/practice/new` → 跳登录或 404
- [ ] 退出后 SW 缓存的页面 → 重新打开要求登录（不能直接看）
- [ ] 笔记是私有的（用 B 账号登录看不到 A 的笔记）
