## 优先级定义

- **P0**：阻塞上线 / 数据丢失 / 安全风险 → 立即修
- **P1**：影响核心功能体验 / 移动端主流程 → v1.1 修
- **P2**：边角体验 / 文案 / 视觉 → v1.1 / v1.2 修

## P1（影响主流程）

### [P1-001] iOS PWA 离线时 SW 被冻结
- **现象**：iOS 设备锁屏 1-2 小时后，PWA 中断网，SW 状态不更新
- **影响**：离线写操作入队后，**联网重新打开 app 才同步**（依赖 `online` 事件）
- **绕开**：用户感知到的延迟是"切回 app 后几秒内同步完"
- **计划**：v1.1 评估 Background Sync API 在 iOS 的可用性（目前不可用），改用 Service Worker `sync` 事件 + 用户打开 app 触发双保险
- **状态**：已记录，无修复计划（iOS 平台限制）

### [P1-002] 多选判分严格相等
- **现象**：选 `B` 和选 `b`、`BD` 和 `DB` 算对；但 `BCD` 和 `BCD.` 算错（normalize 不去标点）
- **影响**：极小（用户输入基本都规范）
- **计划**：v1.1 改 `judge` 函数加 strip
- **状态**：已记录，v1.1 修

### [P1-003] `wrong.notes` 没有字数限制
- **现象**：用户可以粘贴一个超长笔记
- **影响**：UI 列表页可能变形
- **计划**：v1.1 加客户端 2000 字限制 + 服务端 5000 字限制
- **状态**：已记录

## P2（边角体验）

### [P2-001] 首页 Dashboard 没有"最近答题"快捷入口
- **现象**：想看刚才答的题要在题库里翻
- **影响**：v1 spec 没要求
- **计划**：v1.1 在 Dashboard 加"最近 5 题"卡片（从 Attempt 查）
- **状态**：已记录

### [P2-002] 错题本没有"按模块筛选"快捷按钮
- **现象**：模块筛选要展开 dropdown
- **影响**：移动端 dropdown 略难用
- **计划**：v1.1 改为横向滚动 chip
- **状态**：已记录

### [P2-003] 计划详情页没有"复制到下周"功能
- **现象**：每周都要重新建计划
- **影响**：常用流程变繁琐
- **计划**：v1.2 评估
- **状态**：已记录

### [P2-004] 题库页没有搜索框
- **现象**：题目多了找不到
- **影响**：v1 数据量小，5 模块各 20 题 100 题不需要
- **计划**：v1.1 加题数 > 500 时启用
- **状态**：已记录

### [P2-005] 错题重做页没有"标记已掌握"按钮
- **现象**：要答对 3 次才自动掌握，等不及
- **影响**：想快速标掌握需要手动 SQL（不可能）
- **计划**：v1.1 加"强制标记掌握"按钮，**需要二次确认**
- **状态**：已记录
